Hands-on projects built around vulnerability management, SOC monitoring, attack simulation, and network defense. Each one shows what I built, how it works, and the security concepts behind it.

01PYTHON · FLASK · NMAP

Centralized Vulnerability Management Dashboard

Web dashboard designed to scan, aggregate, and visualize vulnerabilities in lab systems.

CVSS SeverityHost PrioritizationRisk LogsSOC Reporting
Nmap scan→Aggregate findings→CVSS severity→Prioritize hosts→Risk logs & views

WHAT I BUILT

A custom web application dashboard to scan, aggregate, and visually represent lab-system vulnerabilities.

HOW IT WORKS

It uses Nmap results, applies CVSS-based severity and host prioritization, then organizes findings into remediation-oriented views and risk logs.

SECURITY CONCEPTS INVOLVED

  • Vulnerability scanning and the vulnerability management lifecycle
  • CVSS-based severity scoring
  • Host and risk prioritization
  • Remediation-oriented reporting for SOC teams

WHAT THIS PROJECT SHOWS

  • Python and Flask web development applied to security
  • Turning raw scan output into decisions a team can act on
  • Thinking in terms of risk, not just a list of findings

03VIRTUALIZATION · WIRESHARK

IP Spoofing & Network Packet Analysis System

Sandboxed multi-VM network used to monitor abnormal session signatures and evaluate controlled IP spoofing scenarios.

Packet MonitoringTCP/IP AnalysisFirewall RulesDetection
Multi-VM network→Controlled spoofing→Packet / header analysis→Ingress & egress rules→Evaluate defence

WHAT I BUILT

A sandboxed multi-VM network infrastructure to monitor and isolate abnormal client-server session signatures.

HOW IT WORKS

Controlled IP-spoofing scenarios are analysed through packet/header behaviour, followed by ingress and egress firewall-rule changes to evaluate defensive boundaries.

SECURITY CONCEPTS INVOLVED

  • IP spoofing and TCP/IP header behaviour
  • Packet capture and protocol analysis with Wireshark
  • Ingress and egress firewall filtering
  • Isolating abnormal client-server sessions

WHAT THIS PROJECT SHOWS

  • Deep understanding of how network traffic behaves
  • Testing defences instead of assuming they work
  • Building safe, isolated lab environments with virtualization
